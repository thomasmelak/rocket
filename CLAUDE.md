# CLAUDE.md — rocket

A single-page 3D "spaceship header" demo: a rusty orange spaceship flying through
streaking, colored stars, rendered with Threlte (Three.js for Svelte) and bloom
post-processing. Deployed as a static site to GitHub Pages under `/rocket`.

> Full reference: **[DOCUMENTATION.md](./DOCUMENTATION.md)** covers the
> architecture, per-component behavior, build/deploy, current health, and known issues.
> Keep both files in sync when you change behavior.

## Stack

- **SvelteKit 2 + Svelte 5** (`@sveltejs/adapter-static`, SPA fallback `index.html`)
- **Threlte 8** (`@threlte/core`, `@threlte/extras`) on **three 0.178**
- **Tailwind CSS 4** via `@tailwindcss/vite` (`src/app.css` only imports tailwind)
- TypeScript, ESLint 9 (flat config), Prettier (svelte + tailwind plugins)
- Node 22; `.npmrc` sets `engine-strict=true`

Installed but unused: `@theatre/core`, `@threlte/theatre`, `postprocessing`,
`gl-noise`, `three-custom-shader-material`, `@types/animejs`, `@types/three-nebula`.
Bloom uses `three/addons/postprocessing`, not the `postprocessing` package.

## Functionality map

```
src/
  app.html              HTML shell (favicon, viewport, preload-on-hover)
  app.css               @import 'tailwindcss'
  routes/
    +layout.svelte      Imports app.css, renders children
    +page.svelte        Full-viewport (100vw x 100vh) <Canvas> hosting <Scene/>
  lib/
    Scene.svelte        Camera, controls, render pipeline, env map; composes ship + stars
    spaceship.svelte    GLTF model + engine-beam cone (generated by @threlte/gltf, then edited)
    Stars.svelte        150 instanced streaking stars
    index.ts            Empty ($lib barrel placeholder)
static/                 Copied verbatim into build/
  spaceship-1k.glb      4.3 MB, shown first (PNG, 1024² textures)
  spaceship-4k.glb      13 MB, swapped in when loaded (WebP, 4096² textures)
  energy-beam-opacity.png  Alpha map for the engine beam
  star.png              Alpha map for star streaks
  favicon.svg
.github/workflows/build.yml   Build + deploy to GitHub Pages
```

Component tree: `+layout` → `+page` → `<Canvas>` → `Scene` → { camera + `OrbitControls`, `Spaceship` (bind:ref), `Stars` }.

### `Scene.svelte`
- **Camera:** `PerspectiveCamera` + `OrbitControls` (damping 0.1, autoRotate,
  target origin). `MediaQuery('(max-width: 768px)')` switches between mobile
  (`[-12,2,-5]`, FOV 48, rotate speed 2) and desktop (`[-8,6,10]`, FOV 24, speed 0.5).
- **Render pipeline:** a custom `useTask` on `renderStage` calls
  `EffectComposer.render()`: `RenderPass` → `UnrealBloomPass` (0.275, 1, 0) → `OutputPass`.
  The passes are added in `onMount`.
- **Live reflections:** each frame it hides the ship, renders the scene into a PMREM env
  map, and assigns that map to the ship's materials (`envMapIntensity` 100,
  `normalScale` 0.3). Background is `#598889` × 0.05.
- **Mouse-follow spring** (`translY`/`angleZ`) is implemented but inert, because the
  `pointermove` handler is commented out. Its `mesh`/`raycaster`/`pointer` objects are unused.

### `spaceship.svelte`
- **Progressive loading:** `useGltf` loads `spaceship-1k.glb` and renders it. After it
  resolves, `useGltf().load()` fetches `spaceship-4k.glb`, but only when
  `maxTextureSize >= 4096` and Save-Data is off (`canUseHiRes()`). When the 4K model arrives,
  `hiRes` is set, `{@const gltf = hiRes ?? lowResGltf}` swaps meshes in place, and the 1K
  model's GPU resources are disposed. If the 4K load fails, the 1K model stays.
- **Both GLBs must keep identical node and material names**, because the swap depends on it.
  See DOCUMENTATION.md §4.3.2 for how the 4K file was optimized
  (near-lossless WebP; lossy WebP looked barely better than the 1K).
- Also loads `/rocket/energy-beam-opacity.png`.
- `alphaFix` makes the `spaceship_racer` and `cockpit` materials transparent with alpha-to-coverage.
- Renders 13 GLTF meshes in a group scaled 0.003, plus an additive-blended
  orange-red open cone as the engine beam (`tail = 2000`).
- API: `export const ref` (Group), `$$restProps`, and slots `fallback`, `error` and default
  (legacy Svelte 4 syntax).
- **Model credit:** "Rusty Spaceship - Orange" by Sousinho, CC-BY-4.0. Keep this attribution.

### `Stars.svelte`
- One `InstancedMesh` of a `[1, 0.05]` plane with the `star.png` alpha map, 150 instances.
- Random position, length, speed (19.5–42) and color from
  `#F46036 #EFCA08 #593C8F #E71D36 #BBDEF0`. 20% spawn in a near band, 80% in a far field.
- `useTask` moves stars along +X and re-randomizes them past `x > 50`. `@ts-nocheck`.

## Deployment

`build.yml` runs on push and PR to `main`: checkout → Node 22 → `npm i` → `npm run build`
→ upload `build/` → `deploy-pages`. `svelte.config.js` sets `paths.base = '/rocket'`,
`precompress: true` and `fallback: 'index.html'`.

## Gotchas

- **Base path is hardcoded in asset URLs**: `Stars.svelte` and `spaceship.svelte` load
  `/rocket/...` literally. If `paths.base` changes, update them (better: use `base` from `$app/paths`).
- **Possible double render**: the `Canvas` doesn't set `autoRender={false}`, although
  `Scene`'s comment assumes it does. Verify before touching render code.
- **PMREM env map is rebuilt every frame**, which is the main GPU cost.
- **4K uses ~0.5 GB of VRAM** after the swap (WebP only shrinks the download). To skip it on
  small screens or weak devices, extend `canUseHiRes()`.
- **Mixed style**: `Scene` is plain JS with `@ts-ignore`, `Stars` is `@ts-nocheck`, and
  `spaceship` uses legacy slots. `.prettierrc` uses tabs, but these files use 2 spaces.
- The CI workflow deploys on PRs too and has no `environment: github-pages` block.
  It uses `npm i` rather than `npm ci`. Pages source must be set to "GitHub Actions".
- `package.json` name is `rocket-ship`; `README.md` is the unmodified `sv` template.
