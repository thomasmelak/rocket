# CLAUDE.md — rocket

A single-page 3D "spaceship header" demo: a rusty orange spaceship flying through
streaking, colored stars, rendered with Threlte (Three.js for Svelte) and bloom
post-processing. Deployed as a static site to GitHub Pages under `/rocket`.

## Stack

- **SvelteKit 2 + Svelte 5** (`@sveltejs/adapter-static`, SPA fallback `index.html`)
- **Threlte** (`@threlte/core`, `@threlte/extras`; `@threlte/theatre` / `@theatre/core` installed but unused) on **three 0.178**
- **Tailwind CSS 4** via `@tailwindcss/vite` (`src/app.css` just imports tailwind)
- TypeScript, ESLint 9, Prettier (svelte + tailwind plugins)
- Node 22 (CI); `.npmrc` sets `engine-strict=true`

Unused deps: `postprocessing`, `gl-noise`, `three-custom-shader-material`,
`@types/animejs`, `@types/three-nebula`.

### `Scene.svelte`
- **Camera:** `PerspectiveCamera` with `OrbitControls` (damping, autoRotate,
  target origin). Mobile (`MediaQuery` `max-width: 768px`) uses a different position
  `[-12,2,-5]`, FOV 48, rotate speed 2; desktop `[-8,6,10]`, FOV 24, speed 0.5.
- **Render pipeline:** takes over rendering via a `useTask` on `renderStage`
  (the Canvas must have autoRender disabled for this to be the only render — see Gotchas).
  `EffectComposer` = `RenderPass` → `UnrealBloomPass` (strength 0.275, radius 1, threshold 0) → `OutputPass`. Passes are added in `onMount`.
- **Environment map each frame:** hides the ship, renders the scene (stars) to a
  PMREM cube, sets it as `envMap` on ship materials that have `envMapIntensity`
  (intensity 100, normalScale 0.3), then shows the ship. Scene background is `#598889` × 0.05.
- **Pointer-follow spring motion** (`translY`, `angleZ` with stiffness/damping) is
  implemented but inert: the `pointermove` handler in `onMount` is commented out, so
  `intersectionPoint` is never set and the ship stays at the origin.
- Renders `<Spaceship bind:ref position rotation>` and `<Stars />`.

### `spaceship.svelte`
- Loads `/rocket/spaceship-1k.glb` (`useGltf`) and `/rocket/energy-beam-opacity.png` (`useTexture`).
- `alphaFix` makes the `spaceship_racer` and `cockpit` materials transparent with
  alpha-to-coverage and depth test/write.
- Renders each mesh node of the GLTF (hull parts, cockpit) inside a scaled
  (0.003) group, plus an additive-blended orange-red open cylinder as the engine beam (`tail = 2000`).
- Exposes `ref` (a `Group`), `fallback`/`error` slots, and a default slot. Uses
  Svelte 4-style `$$restProps` / `<slot>` (legacy syntax inside a Svelte 5 app).
- Model credit: "Rusty Spaceship - Orange" by Sousinho, CC-BY-4.0 (Sketchfab). Keep this attribution.

### `Stars.svelte`
- 150 stars as one `InstancedMesh` of a thin plane (`[1, 0.05]`) with `star.png` alpha map.
- Each star has a random position, length (scale X), speed (19.5–42), and color from
  `#F46036 #EFCA08 #593C8F #E71D36 #BBDEF0`.
- `useTask` moves stars along +X; past x > 50 they are re-randomized (`resetStar`). 20% spawn in a near band, 80% in a wider far field.
- File uses `// @ts-nocheck`.

## Deployment

`build.yml` runs on push/PR to `main`: checkout → Node 22 → `npm i` →
`npm run build` → upload `build/` → `deploy-pages`.
`svelte.config.js` sets `paths.base = '/rocket'`, so the site is served at
`https://<user>.github.io/rocket/`.

## Gotchas

- **Base path is hardcoded in asset URLs**: `Stars.svelte` and `spaceship.svelte`
  load `/rocket/...` literally. If `paths.base` changes, or in local dev where assets
  are served at `/rocket/` by SvelteKit, update these (better: use `$app/paths` `base`/`asset`).
- `Scene.svelte` relies on a custom render loop; the `Canvas` in `+page.svelte` does
  not set `autoRender={false}` explicitly, so the scene may render twice (once by
  Threlte, once by the composer). Verify before changing render code.
- `Scene.svelte` is plain JS (no `lang="ts"`) with `@ts-ignore` comments; `Stars.svelte` is `@ts-nocheck`, so `svelte-check` coverage is limited there.
- `package.json` name is still `rocket-ship`; `README.md` is the unmodified `sv` template.
- The CI workflow deploys on pull requests too, and the deploy job lacks an `environment: github-pages` block.
- Formatting is mixed: `.prettierrc` uses tabs, while `Scene`, `Stars` and `spaceship` use 2-space indentation.
